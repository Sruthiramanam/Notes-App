# 📝 Notes App

A simple, responsive Notes App built with HTML, CSS, and JavaScript. It allows users to create, edit, delete, and search notes, with automatic saving using the browser's local storage.

## ✨ Features

- ➕ **Create Notes** — Add new notes instantly.
- ✏️ **Edit Notes** — Update note content directly in the text area.
- 🗑️ **Delete Notes** — Remove notes with a confirmation prompt.
- 🔍 **Search Notes** — Find notes by matching words or phrases.
- 💾 **Automatic Saving** — Notes are saved in browser local storage.
- 🔄 **Persistent Storage** — Notes remain available after refreshing the page in the same browser.
- 📱 **Responsive Design** — Works on desktop and mobile screens.
- ⚠️ **Empty States** — Helpful messages appear when there are no notes or search results.

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling, grid layout, and responsive design
- **JavaScript** — Note management, search, and DOM manipulation
- **Local Storage** — Saving notes in the browser

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click **+ Add Note** to create a note.
5. Type your content and use the search box to find notes.

No installation or external API key is required.

## 💾 Data Storage

The application uses the browser's `localStorage` to save notes automatically.

- Notes remain saved after a page refresh.
- Notes are stored locally in the browser.
- Clearing the browser's site data may delete saved notes.
- Notes are not synchronized across different browsers or devices.
